Friends & Testimonials

Work

  1. NVIDIATypeScript

    GPU Power Model

    Predicts a GPU’s power long before the chip exists.

    You draw the chip as blocks wired to power rails and clocks, change a clock or a voltage, and the watts update as you edit. I rewrote it from scratch in TypeScript, and my team’s Python notebooks run the same engine.

  2. NVIDIAWon NTech 2025

    PACE

    A chatbot that answers questions from my team’s docs.

    PACE stands for Power Architecture Chat Engine. New interns ask it things instead of digging through Confluence, and when it got an answer wrong, it was usually an outdated page, so we fixed those too. It won NTech 2025, NVIDIA’s internal paper contest.

  3. Side projectLive

    Lokasu

    Things I build on weekends. The site and its Launch Check are live.

    lokasu.comLaunch Check

    I designed and coded lokasu.com, where 3D models morph into each other and your cursor pushes them around. Launch Check is free. Paste a link and see what will break when you share it. Two more products are on the way.

  4. AISweden

    Vilje Tech

    I build ViljePDF, ViljeCAD and Inwoice for Nordic companies.

    Vilje Tech is an AI and automation company in Helsingborg, Sweden. ViljePDF reads engineering drawings that are just images and lets a person check every value, ViljeCAD turns drawing PDFs into 3D models, and Inwoice moves supplier invoices from inbox to books.

  5. SpringerCollege

    StarCraft II Paper

    My final-year project, published as a Springer chapter.

    Springer

    Our agent chose between big tactics, like gathering resources or training units, where the usual RL agents learn one click at a time. It beat DeepMind’s baseline agent at those and lost badly in actual fights.

  6. Open sourceMerged

    Continue PR

    My merged PR adding NVIDIA NIM embeddings to Continue.

    GitHub

    Continue is a popular open-source AI coding assistant. I added NVIDIA NIM as an embeddings provider, so it can index your code with NVIDIA’s models.

  7. JavaScriptD3

    d3-hwschematic

    Hardware schematics in the browser, built on Michal Orsák’s original.

    GitHubOriginal

    Michal Orsák’s d3-hwschematic draws interactive schematics of hardware designs with D3 and ELK. In 2024 I reworked how it draws nodes and wires. The original and all the hard parts are his.

  8. ShellLinux

    dotfiles

    One command turns a bare machine into my setup.

    GitHub

    It sets up zsh, Powerlevel10k, WezTerm, mise and friends on Rocky Linux, Ubuntu, macOS or WSL. Without sudo, it installs everything into my home folder instead, and every config is a symlink back to the repo.

  9. AndroidFirebase
