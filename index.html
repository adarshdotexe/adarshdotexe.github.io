About

The childhood obsession with tech never wore off. Now it pays rent.

I'm on NVIDIA's Power Architecture Analysis team, where I turn slow, manual workflows into tools people actually want to open. Rust on the back, React on the front, Python for everything else. I develop AI-first: Claude Code and friends are permanent residents of my terminal.

After hours I squeeze vision models onto Intel NUCs for retail analytics. Before all this: computer science at NIT Andhra Pradesh, class of 2024, and an unhealthy number of clubs.
